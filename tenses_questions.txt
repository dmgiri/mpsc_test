1. Every Monday, she ____ a report.
 (1) write
 (2) writes
 (3) writing
 (4) written
Answer: 2
Explanation: She is third-person singular, so use writes. Memory trick: He/She/It → verb+s/es

2. Look! She is ____ a report.
 (1) write
 (2) writing
 (3) wrote
 (4) written
Answer: 2
Explanation: Use is/am/are + verb-ing. Memory trick: NOW → am/is/are + ing

3. She has already ____ a report.
 (1) wrote
 (2) written
 (3) writing
 (4) write
Answer: 2
Explanation: Has + past participle. Memory trick: HAS/HAVE → V3

4. She has been ____ a report since morning.
 (1) write
 (2) written

 (4) wrote
Answer: 3
Explanation: Has been + -ing expresses ongoing activity. Memory trick: SINCE/FOR → has/have been + ing

Answer: 2
