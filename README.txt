GEOMETRY LEARNING UPDATE
========================
Open index.html, then Geometry. Alternatively, open geometry.html directly.

NEW FOR EVERY GEOMETRY QUESTION
- Marathi concept explanation and applicable formula.
- Step-by-step worked solution, quick method and memory trick.
- Common mistake / scope caution.
- Practice-only hint before revealing the answer.

HOW TO READ THE SOLUTIONS
1. On Geometry setup, click "Solutions & memory tricks" to revise all questions without taking a test.
2. In Untimed practice, select an option and click "Check answer".
3. In a Timed exam, submit to view full solutions in Answer review.
The revision room is blocked while an unfinished timed Geometry attempt exists.

OPENING
Extract the entire ZIP into one folder. Open index.html in a full browser such as Chrome, Edge, Firefox or Safari. Each topic HTML is self-contained and can also be opened directly. No server or installation is required. Enable JavaScript. Do not use a restricted email/attachment preview.

WORDING AND PYQ POLICY
Question text is Unicode text, not screenshots. Seven Marathi items cite identifiable MPSC papers or source listings. Adapted PYQs are expressly marked; authored important practice is not represented as a past-paper transcription or a reliable prediction of future questions.
Online Geometry and some Marathi items use Marathi adaptations. Numerical conditions, answer choices and conceptual content were retained, with explanations written for this portal. Adapted items are NOT claimed to preserve verbatim original wording. The original uploaded-paper questions are distinguished in their source notes. Every source-listed PYQ has an exam reference and either a public URL or the uploaded PDF filename/page/question reference. Online exam attributions follow the cited publisher, not independent verification of every official paper. The latest years and dates are the labels on those sources.
Original English/Chemistry question content was preserved, not re-audited as an official answer key. Old unsubstantiated 'most asked', 'high chance' and predictive badges are not carried into this interface. Priority labels are revision guidance only. Marathi phonetic groupings follow conventional school/exam grammar; different linguistic analyses and alphabet-count conventions exist.

INTERACTION
Timed exam / untimed practice; customizable duration and negative marking; source/topic filters; optional question and option shuffling; optional reshuffling on reload; optional answer lock; question navigator; review flags; clear answer; check-answer in practice; scratch notes; save/resume; auto-submit when time expires; explanations; raw and weighted score; per-topic performance; review search/filter; retry wrong/unanswered; 70%+ celebration; 20-attempt history; CSV/JSON exports; JSON backup/import; print report; adjustable font; Mocha/Latte themes; responsive mobile/desktop.
Original option numbers are kept separately from displayed letters. Answer IDs remain stable during shuffling. Keyboard 1–4 selects displayed positions; N/P navigate and R flags, when focus is not on an input/control.

SAVING AND SCORING
Progress is local to each browser/device. No cloud account, analytics or sync. Private browsing, deleting browser storage, moving files or browser-specific file:// restrictions can affect persistence. Export Backup before moving devices or clearing browser data. Import only a compatible backup for the same topic. Unfinished timed exams keep their original deadline, including time spent away or after importing. Practice elapsed time includes time away. This is a static personal practice app, not a secure proctored exam system.
Default durations and +1 scoring are practice settings, not official exam prescriptions. Optional wrong-answer deductions are configurable. Accuracy is correct divided by attempted answers; percentage is correct divided by questions in the session. Performance-based focus advice is not exam-frequency analysis. Cancelled Q69 pertains only to the retained full-paper portal, not these topic banks.
