GDP आणि GNP यांतील मुख्य फरक कोणता?

⭕ A) GDP मध्ये फक्त शेतीचा समावेश होतो
⭕ B) GNP मध्ये परदेशातून मिळणारे निव्वळ घटक उत्पन्न विचारात घेतले जाते

I = Investment
G = Government Expenditure
X = Exports
